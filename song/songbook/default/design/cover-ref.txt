# Cover (wallpaper) reference for the default rice.
#
# The shipped default has no bundled cover (wallpapers are large and user-specific).
# song/covers/ is the user's wallpaper library; `rice gen <wallpaper>` extracts
# a palette from an image and stores it there.
#
# For bootstrap: any dark-toned wallpaper works with Catppuccin Mocha.
# Suggested starting point: a solid #1e1e2e fill, or any Catppuccin-themed art.
#
# To set a cover for this rice at runtime:
#   aoide rice adopt default --cover ~/path/to/wallpaper.png
#
# The cover path will be written to song/stage/cover.json and AoideWallpaper.qml
# will hot-load it.
PLACEHOLDER: no cover bundled — see song/covers/ for the user wallpaper library.
