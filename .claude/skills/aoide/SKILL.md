# Aoide onboarding route

1. Run `aoide guide` (and `lyra guide` for paint work) — identity, the
   four tiers, and the live command table, derived from the binary itself.
2. In the Aoide repo: read root `AGENTS.md` (the nine house rules), then
   `docs/agent/README.md` (the read order) and `docs/agent/session.md`
   (the mechanical session checklist).
3. Command-surface ground truth at any tier: `aoide schema --json` /
   `lyra schema --json`.

The rules live where the routes point — this file never copies them.
